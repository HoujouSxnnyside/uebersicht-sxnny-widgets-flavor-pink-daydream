# Contributing to Sxnny Pink Daydream

Contributions are welcome — bugs, fixes, features, or documentation.
This document covers how to work with the project as a contributor.

---

## Setup

Requires macOS 14+, [Bun](https://bun.sh), [Swift](https://swift.org) 6+ and [Just](https://github.com/casey/just).

```bash
just install
just dev
```

## Before Opening a Pull Request

- Run `just check` — it must pass (lint, format, typecheck, tests).
- Use [Conventional Commits](https://www.conventionalcommits.org/) for every commit message.
- Keep code, comments and documentation in English, and use icons or SVG stickers instead of raw emojis.
- Read [CLAUDE.md](CLAUDE.md) for architecture and conventions.
